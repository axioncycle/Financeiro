01 — FILOSOFIA

Cada elemento tem uma função

Nada existe só porque é bonito. Todo componente deste sistema precisa cumprir pelo menos uma destas funções — este é o filtro de decisão do design.

→

Vender

Levar o produto e o preço ao centro; CTA sempre claro.

→

Gerar confiança

INMETRO, garantia e prova social visíveis no ticket alto.

→

Orientar

Guia, comparador e hierarquia clara reduzem indecisão.

→

Reduzir objeção

Compatibilidade e WhatsApp tiram o medo de errar.

Personalidade visual: premium · minimalista · esportiva · tecnológica · sofisticada. O azul é energia estratégica (CTA, dado-chave, estado ativo) — nunca banha a tela. O produto é sempre o protagonista.
